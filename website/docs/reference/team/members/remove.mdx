# rt team members remove

`rt › team › members › remove`

Revoke forge access, drop the roster entry, and re-encrypt without the member's key

## Usage

```bash
rt team members remove <handle> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<handle>` | text |  | The member's forge username |
| `--key` | text |  | The recipient to remove, if it isn't recorded on the roster (a hand-edited store, a suspect entry) |
| `--team` | text |  | Which cloned team to remove from; omit when only one is cloned |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
