# rt setup pack

`rt › setup › pack`

Install a pack's plugins + skills, then check its pipeline stages resolve

## Usage

```bash
rt setup pack [flags]
```

| Flag / Arg | Type | Default | Description |

| `--team-of-one` | boolean | `false` | Solo install, no team |
| `--ci` | boolean | `false` | Headless CI run |
