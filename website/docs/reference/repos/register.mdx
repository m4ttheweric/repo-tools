# rt repos register

`rt › repos › register`

Add repo paths to the rt index, optionally granting background tracking

## Usage

```bash
rt repos register <path> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<path>` | text |  | Repo path to register (pass more than one to register several at once) |
| `--track` | select |  | Grant background tracking at this level; omit to register without tracking |
| `--caches` | text |  | Comma-separated cache kinds for --track (default branches) |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
