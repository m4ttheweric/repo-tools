# rt repos

`rt › repos`

Register repos with rt (index + tracking)

## Usage

```bash
rt repos
```

## Subcommands

| Command | Description |
| --- | --- |
| [`register`](register) | Add repo paths to the rt index, optionally granting background tracking |
| [`prune`](prune) | Drop index entries whose path is gone, and duplicate names left behind by a repo rename |
| [`locate`](locate) | Tell rt where a repo moved to — re-points the index, worktree registry, endpoint claims and git's worktree admin files together |
