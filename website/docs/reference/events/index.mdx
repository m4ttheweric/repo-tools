# rt events

`rt › events`

Optional event bus for panes and skills

## Usage

```bash
rt events
```

## Subcommands

| Command | Description |
| --- | --- |
| [`emit`](emit) | Publish an event to a topic |
| [`wait`](wait) | Block until a matching event lands (long-poll; exit 124 on timeout) |
| [`tail`](tail) | Stream matching events as NDJSON until interrupted |
| [`list`](list) | Read matching events from the journal (non-blocking) |
