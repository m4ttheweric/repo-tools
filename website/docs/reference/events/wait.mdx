# rt events wait

`rt › events › wait`

Block until a matching event lands (long-poll; exit 124 on timeout)

## Usage

```bash
rt events wait <pattern> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<pattern>` | text |  | Glob pattern (* within a segment, ** across segments) |
| `--after` | text |  | Cursor from a previous response; omit for only-new events |
| `--timeout` | text |  | Give up after this long (30s, 5m, 500ms, bare seconds); omit to wait forever |
