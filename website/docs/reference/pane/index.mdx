# rt pane

`rt › pane`

herdr panes as rt sees them: list with chat presence, peek, spawn claude, cswap accounts, directory suggestions

## Usage

```bash
rt pane
```

## Subcommands

| Command | Description |
| --- | --- |
| [`list`](list) | Claude panes with their chat handle, status and rooms joined in (needs herdr) |
| [`peek`](peek) | The last lines of a pane's visible screen |
| [`spawn`](spawn) | Open a herdr tab in a directory and start claude in it, optionally under a cswap account |
| [`send`](send) | Inject text into a pane as if typed and submitted (--text - reads stdin) |
| [`accounts`](accounts) | cswap accounts with rate-limit headroom, for spawn --account |
| [`directories`](directories) | Repos and worktrees rt knows, as suggestions for spawn --cwd |
