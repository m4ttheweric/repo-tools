# rt home snapshot

`rt › home › snapshot`

Run the snapshot daemon now (or show its status with --status)

## Usage

```bash
rt home snapshot [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--status` | boolean | `false` | Show status instead of snapshotting: enabled, last run/commit, push state, claimed zones |
