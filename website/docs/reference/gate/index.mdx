# rt gate

`rt › gate`

Human-decision gates: pause a subject until answered, parked, or closed

## Usage

```bash
rt gate
```

## Subcommands

| Command | Description |
| --- | --- |
| [`open`](open) | Open a human-decision gate on a subject |
| [`answer`](answer) | Answer an open gate |
| [`wait`](wait) | Block until a gate is answered or closed (default: wait forever) |
| [`list`](list) | List gates |
| [`park`](park) | Park an open gate (paused, not closed) |
| [`close`](close) | Close a gate without an answer |
| [`subscribe`](subscribe) | Subscribe a session to gates opened under a subject prefix |
| [`unsubscribe`](unsubscribe) | Remove a gate subscription |
| [`subscriptions`](subscriptions) | List gate subscriptions |
