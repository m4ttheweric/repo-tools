# rt gate open

`rt › gate › open`

Open a human-decision gate on a subject

## Usage

```bash
rt gate open [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--subject` | text |  | Opaque &lt;prefix&gt;:&lt;id&gt; the gate pauses |
| `--kind` | text |  | Gate kind, free-form |
| `--questions` | text |  | JSON array of questions |
| `--meta` | text |  | Optional JSON metadata |
| [`--agent`](/guides/common-flags) | text |  | Optional opening agent id |
| `--pane` | text |  | Optional herdr pane id, kept as a focus/resume reference (delivery binds to --nudge) |
| `--nudge` | text |  | Optional JSON nudge target |
