# rt gate wait

`rt › gate › wait`

Block until a gate is answered or closed (default: wait forever)

## Usage

```bash
rt gate wait <id> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<id>` | text |  | Gate id |
| `--timeout` | text |  | Give up after this long (30s, 5m, 500ms, bare seconds); omit to wait forever |
