# rt gate list

## Usage

```bash
rt gate list [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--open` | boolean | `false` | Only open (unanswered, unparked) gates |
| `--subject-prefix` | text |  | Filter by subject prefix |
| `--kind` | text |  | Filter by kind |
| `--limit` | text |  | Cap the number of returned gates |
| `--cursor` | text |  | Resume paging from a previous response's cursor |
