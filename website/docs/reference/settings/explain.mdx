# rt settings explain

`rt › settings › explain`

Show the full scope chain for one setting, weakest first

## Usage

```bash
rt settings explain <key> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<key>` | text |  | Namespaced settings key (see rt settings list) |
| [`--repo`](/guides/common-flags) | text |  | Repo name from ~/.mattstack/rt/repos.json — enables repo-scoped rungs |
