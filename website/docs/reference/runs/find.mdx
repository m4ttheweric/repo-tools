# rt runs find

`rt › runs › find`

Runs whose claude-session field matches; read-side, no daemon

## Usage

```bash
rt runs find [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--session` | text |  | Claude Code session id to match against the claude-session field |
| `--running` | boolean | `false` | Keep only status = running matches |
| [`--json`](/guides/common-flags) | boolean | `false` | Accepted and ignored; output is always JSON |
