# rt sdm login

`rt › sdm › login`

Log in to StrongDM (browser popup by default)

## Usage

```bash
rt sdm login [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--manual` | boolean | `false` | Use terminal-based login instead of browser popup |
| `--visible` | boolean | `false` | Show the browser window during login |
