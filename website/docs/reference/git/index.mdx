# rt git

`rt › git`

Git operations (rebase, reset, branch, commit, backup)

## Usage

```bash
rt git
```

## Subcommands

| Command | Description |
| --- | --- |
| [`rebase`](rebase) | Smart rebase onto origin/master with auto-resolve; on conflict, --json/--agent/--no-agent control escalation (--agent needs a TTY and a running herdr) |
| [`reset`](reset) | Safe reset with divergence detection |
| [`branch`](branch) | Branch management (switch, create, rename, clean) |
| [`commit`](commit) | Interactive staged/unstaged commit picker with live diff preview |
| [`backup`](backup) | Back up the current branch |
| [`restore`](restore) | Restore from a backup branch |
| [`pull`](pull) | Pull from origin (mirror of GitHub Desktop's Pull button) |
| [`push`](push) | Push current branch to origin/<branch>, fixing wrong upstream |
| [`upstream`](upstream) | Fix branch upstream to track origin/<branch> |
