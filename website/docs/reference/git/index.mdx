# rt git

`rt › git`

Git operations (rebase, reset, commit, backup)

## Usage

```bash
rt git
```

## Subcommands

| Command | Description |
| --- | --- |
| [`rebase`](rebase) | Smart rebase onto origin/master with auto-resolve |
| [`reset`](reset) | Safe reset with divergence detection |
| [`commit`](commit) | Interactive staged/unstaged commit picker with live diff preview |
| [`backup`](backup) | Back up the current branch |
| [`restore`](restore) | Restore from a backup branch |
| [`pull`](pull) | Pull from origin (mirror of GitHub Desktop's Pull button) |
| [`push`](push) | Push current branch to origin/&lt;branch&gt;, fixing wrong upstream |
| [`upstream`](upstream) | Fix branch upstream to track origin/&lt;branch&gt; |
