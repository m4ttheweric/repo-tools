# rt secrets

`rt › secrets`

sops-encrypted secrets under ~/.mattstack/user/secrets/

## Usage

```bash
rt secrets
```

## Subcommands

| Command | Description |
| --- | --- |
| [`set`](set) | Write a secret (creates the domain file, or one key within it) — value prompted, never a CLI arg |
| [`list`](list) | List a domain's secret names (never prints values) |
| [`rotate`](rotate) | Replace a secret's value; prints the rotation commit message — value prompted, never a CLI arg |
