# rt secrets list

`rt › secrets › list`

List a domain's secret names (never prints values)

## Usage

```bash
rt secrets list <domain> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<domain>` | text |  | Secrets domain (rt, deck, board) |
| `--team` | text |  | List from this team's store instead of your personal one |
