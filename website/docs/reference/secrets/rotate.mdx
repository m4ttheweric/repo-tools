# rt secrets rotate

`rt › secrets › rotate`

Replace a secret's value; prints the rotation commit message — value prompted, never a CLI arg

## Usage

```bash
rt secrets rotate <domain> <key> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<domain>` | text |  | Secrets domain (rt, deck, board) |
| `<key>` | text |  | Key name within the domain |
| `--stdin` | boolean | `false` | Read the new value from stdin instead of a no-echo prompt (scripting) |
