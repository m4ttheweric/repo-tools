# rt herd stop

`rt › herd › stop`

Stop the hidden herdr session that hidden herds run in

## Usage

```bash
rt herd stop [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--hidden` | boolean | `false` | Required: names the hidden session as the target |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the stop record as JSON |
