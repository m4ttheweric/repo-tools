# rt herd spawn

`rt › herd › spawn`

Spawn a worker job: worktree, herdr pane, Claude agent

## Usage

```bash
rt herd spawn [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--herd` | text |  | Herd id (default: HERD_ID) |
| `--job` | text |  | Job name; also the worktree and handle stem |
| `--brief` | text |  | File whose text becomes the job brief |
| `--dir` | text |  | Existing directory to run in instead of a fresh worktree |
| `--model` | text |  | Override agent.model for this worker |
| `--effort` | text |  | Override agent.effort for this worker |
| `--account` | text |  | cswap account for this worker |
| `--disposable` | boolean | `false` | Wrap-up may dispose this job's worktree |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the spawn record as JSON |
