# rt herd close

`rt › herd › close`

Close a worker job (the pane stays; the row stops being live)

## Usage

```bash
rt herd close <job> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<job>` | text |  | Job name |
| `--herd` | text |  | Herd id (default: HERD_ID) |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the close record as JSON |

_See code: [commands/herd.ts › close](https://github.com/m4ttstack/rt/blob/main/commands/herd.ts)_
