# rt herd

`rt › herd`

Run a herd: registry, worker questions as gates, chat room, lifecycle

## Usage

```bash
rt herd
```

## Subcommands

| Command | Description |
| --- | --- |
| [`start`](start) | Start a herd: registry row, chat room, herdr workspace, gate subscription |
| [`spawn`](spawn) | Spawn a worker job: worktree, herdr pane, Claude agent |
| [`ask`](ask) | Worker: opens a gate; end the turn, the answer arrives as a nudge |
| [`milestone`](milestone) | Worker: posts the artifact and opens a milestone gate; end the turn |
| [`answer`](answer) | Worker: read the answer to a gate this job is holding at |
| [`report`](report) | Worker: post a progress report into the herd room |
| [`gates`](gates) | Open gates across a herd's workers |
| [`status`](status) | One herd: jobs, panes, gates, subscription, unread |
| [`list`](list) | Herds on this machine: id, status, room, job count |
| [`resume`](resume) | Re-point a herd's gate subscription and chat handle at this session |
| [`close`](close) | Close a worker job (the pane stays; the row stops being live) |
| [`attend`](attend) | Attach a worker's pane in a tab of your own workspace |
| [`wrap-up`](wrap-up) | Wind a herd down: panes, worktrees, job dirs, room |
| [`stop`](stop) | Stop the hidden herdr session that hidden herds run in |
