# rt daemon track

`rt › daemon › track`

Per-repo background tracking (live/poll/off)

## Usage

```bash
rt daemon track <repo> <level> <caches>
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<repo>` | text |  | Repo name from ~/.rt/repos.json (omit to list; repo alone opens the interactive editor) |
| `<level>` | text |  | live (events + poll), poll (5-min only), off (on-demand only); omit to pick interactively |
| `<caches>` | text |  | Cache kinds, space-separated: branches, project-mrs, discussions (default: branches) |

**Aliases:** `events`
