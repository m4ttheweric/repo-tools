# rt skills materialize

`rt › skills › materialize`

Run merge-manifests.sh to materialize skill bindings for registered repos

## Usage

```bash
rt skills materialize [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--repo`](/guides/common-flags) | text |  | Materialize only this registered repo; omit for every known repo |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
