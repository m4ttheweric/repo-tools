# rt skills

`rt › skills`

Compile, check, and manage the surface of the pack's committed skills

## Usage

```bash
rt skills
```

## Subcommands

| Command | Description |
| --- | --- |
| [`link`](link) | Symlink a skills/*/SKILL.md tree into ~/.claude/skills by frontmatter name (create, repoint, prune; conflicts reported, never touched) |
| [`materialize`](materialize) | Run merge-manifests.sh to materialize skill bindings for registered repos |
| [`compile`](compile) | Compile pack verbs from step sources + manifest bindings into committed SKILL.md files |
| [`check`](check) | Report compiled skills that no longer match their sources |
| [`surface`](surface) | List, set, or apply the pack's public/internal skill surface (bare invocation opens an fzf multi-toggle palette) |
| [`packs`](packs) | List packs discovered from installed marketplace plugins that carry a surface.jsonc |
| [`composition`](composition) | Report the pack's full binding composition -- verbs, slots, fills, and every binder in the manifest (roster and stages both) |
| [`bind`](bind) | Write bindings.&lt;engineRef&gt;.&lt;slot&gt; = &lt;fill&gt; into the manifest (jsonc-parser, comments preserved), validate the fill against the slot's contract, and recompile (a stage bind recompiles the whole pack) |
