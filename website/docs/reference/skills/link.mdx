# rt skills link

`rt › skills › link`

Symlink this repo's skills/*/SKILL.md into ~/.claude/skills by frontmatter name (create, repoint, prune; conflicts reported, never touched)

## Usage

```bash
rt skills link [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--dry-run`](/guides/common-flags) | boolean | `false` | Print what would change without touching disk |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
