# rt services

`rt › services`

App-registered services (daemon, deck) via mattstack.app

## Usage

```bash
rt services
```

## Subcommands

| Command | Description |
| --- | --- |
| [`list`](list) | List LaunchAgents mattstack.app has registered |
| [`register`](register) | Ask mattstack.app to register the daemon (and deck, when bundled) LaunchAgents |
| [`restart`](restart) | Ask mattstack.app to restart a registered LaunchAgent |
