# rt services register

`rt › services › register`

Ask mattstack.app to register the daemon (and deck, when bundled) LaunchAgents

## Usage

```bash
rt services register [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--plist` | text |  | Plist filename to register (repeatable); omit for the default set |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
