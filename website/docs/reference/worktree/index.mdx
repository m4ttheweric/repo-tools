# rt worktree

`rt › worktree`

Worktree lifecycle (provision/dispose/list) + worktree-wide operations

## Usage

```bash
rt worktree
```

## Subcommands

| Command | Description |
| --- | --- |
| [`provision`](provision) | Claim a worktree for a ticket or branch (from the on-deck pool, or freshly created) |
| [`create`](create) | Create a fresh worktree (optionally straight into the on-deck pool) |
| [`dispose`](dispose) | Dispose a worktree (no target + TTY → picker) |
| [`list`](list) | List worktrees |
| [`freshen`](freshen) | Freshen worktrees (no arg + TTY → picker over freshenable trees) |
| [`adopt`](adopt) | One-shot migration: adopt an unmanaged repo's worktrees into the registry |
| [`each`](each) | Run a command in each worktree (--all | --on-deck, else pick) |
