# rt worktree ready-approve

`rt › worktree › ready-approve`

Approve a repo's team-authored `ready` shell before it runs (no repo + TTY → picker)

## Usage

```bash
rt worktree ready-approve [<repo>] [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<repo>` | text |  | Repo whose team `ready` ladder to approve; omit to pick interactively |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the raw result as JSON |
