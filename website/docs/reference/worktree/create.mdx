# rt worktree create

`rt › worktree › create`

Create a fresh worktree (optionally straight into the on-deck pool)

## Usage

```bash
rt worktree create [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--repo`](/guides/common-flags) | text |  | Registered repo name (defaults to the current repo) |
| `--on-deck` | boolean | `false` | Put the new tree in the on-deck pool instead of claiming it |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the raw result as JSON |
