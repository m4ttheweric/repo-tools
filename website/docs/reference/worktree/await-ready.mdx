# rt worktree await-ready

`rt › worktree › await-ready`

Wait for a claimed tree's background ready steps to settle (no tree + TTY → picker)

## Usage

```bash
rt worktree await-ready <tree> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tree>` | text |  | Claimed tree to wait on; omit to pick interactively |
| [`--repo`](/guides/common-flags) | text |  | Registered repo name (defaults to the current repo) |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the raw result as JSON |
