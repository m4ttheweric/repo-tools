# rt worktree restore

`rt › worktree › restore`

Restore a disposed worktree from its retained trash entry (no target + TTY → picker)

## Usage

```bash
rt worktree restore <tree> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tree>` | text |  | Disposed tree name to restore; omit to pick interactively |
| [`--repo`](/guides/common-flags) | text |  | Registered repo name (defaults to the current repo) |
| `--list` | boolean | `false` | List restorable entries instead of restoring one |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the raw result as JSON |
