# rt worktree freshen

`rt › worktree › freshen`

Freshen worktrees (no arg + TTY → picker over freshenable trees)

## Usage

```bash
rt worktree freshen <tree> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tree>` | text |  | Tree name to freshen; omit to pick interactively (or run for every repo, headless) |
| [`--repo`](/guides/common-flags) | text |  | Narrow to this registered repo |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the raw result as JSON |
