# rt tools setup

`rt › tools › setup`

Run a tool's own post-install setup (herdr integration, fast-browser runtime, editor extension)

## Usage

```bash
rt tools setup <tool> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tool>` | text |  | Tool name (herdr, fast-browser, extension) |
| `--config-dir` | text |  | Extra Claude config dir to set up (repeatable); herdr's own CLAUDE_CONFIG_DIR + ~/.claude are always included |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
