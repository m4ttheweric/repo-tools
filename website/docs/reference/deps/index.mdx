# rt deps

`rt › deps`

Bundled tools: resolve by absolute path, expose on PATH with tagged links

## Usage

```bash
rt deps
```

## Subcommands

| Command | Description |
| --- | --- |
| [`resolve`](resolve) | Show where a tool actually runs from — bundled, a user copy on PATH, or unresolved |
| [`link`](link) | Expose a bundled tool at ~/.local/bin/&lt;tool&gt; (symlink, or a tagged wrapper for multi-argv tools) |
| [`unlink`](unlink) | Remove a tagged link (only ever removes rt's own links, never a user's file) |
| [`reconcile`](reconcile) | Auto-unlink any tagged link whose tool now has a genuine user copy elsewhere on PATH |
