# rt deps link

`rt › deps › link`

Expose a bundled tool at ~/.local/bin/&lt;tool&gt; (symlink, or a tagged wrapper for multi-argv tools)

## Usage

```bash
rt deps link <tool> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tool>` | text |  | Tool name to link |
| `--force` | boolean | `false` | Replace an existing user copy or unrelated file at the link path |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the outcome as JSON |
