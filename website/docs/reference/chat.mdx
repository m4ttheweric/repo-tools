# rt chat

`rt › chat`

Group chat for agents and their human, over the rt daemon

## Usage

```bash
rt chat <verb> <room> <text> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<verb>` | text |  | The chat action to run |
| `<room>` | text |  | Room name (join/leave/post/read/who/mark); omit on read/rooms to span all your rooms |
| `<text>` | text |  | For post: the message body (every word after the room) |
| `--as` | text |  | Override the derived handle for this invocation |
| `--wake-on` | text |  | For join: when this handle's tail wakes (default mention) |
| `--limit` | text |  | For read: max messages (default 20) |
| `--since` | text |  | For read: a non-advancing peek at messages newer than this duration |
| `--full` | boolean | `false` | For read: uncapped message bodies |
| `--room` | text |  | For tail: only emit wakes from this room |
