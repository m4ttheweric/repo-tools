# RT Context extension

The `rt-context` VS Code/Cursor extension shows your current worktree, branch, and linked Linear ticket in the status bar, so you always know which context you're in without running a command.

It's installed automatically by Homebrew, so most people never need to think about it.

## Status bar

```
📁 main-worktree  │  🔖 CV-1287: Add damage photo uploads
```

Clicking the item opens the linked Linear ticket directly.

## Reinstalling or adding editors

```bash
rt settings extension
```

This opens a fuzzy picker to select which editors (Cursor, VS Code, Antigravity, and the like) to install into. Use it to reinstall after an editor update, or to add the extension to an editor Homebrew didn't originally target.

See the full command reference: [`rt settings extension`](/reference/settings/extension).
