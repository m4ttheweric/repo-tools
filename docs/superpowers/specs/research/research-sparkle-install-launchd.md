- SPM: `.package(url: "https://github.com/sparkle-project/Sparkle", from: "2.9.6")`, product "Sparkle". Non-Xcode gotchas: link flag `-Xlinker -rpath -Xlinker @executable_path/../Frameworks`; copy `.build/artifacts/sparkle/Sparkle/Sparkle.xcframework/macos-arm64_x86_64/Sparkle.framework` → Contents/Frameworks with `cp -R`/ditto (preserve symlinks; never unzip); per-arch swift build + lipo for universal (openclaw, CodexBar, symfony-cli-menubar, muxy do this). Missing rpath → dyld Library not loaded.
- Signing: inside-out, NO --deep (corrupts XPC sigs; notarization passes but updates fail): Installer.xpc → Downloader.xpc (--preserve-metadata=entitlements) → Autoupdate → Updater.app → Sparkle.framework → helpers → app; all `-o runtime --timestamp`. Don't rename Sparkle XPC bundle ids. Non-sandboxed: may delete Versions/B/XPCServices.
- Info.plist: SUFeedURL (https), SUPublicEDKey, numeric increasing CFBundleVersion (Sparkle compares this!), SUEnableAutomaticChecks, SUScheduledCheckInterval (≥3600), SUAutomaticallyUpdate (silent download, install on quit), SUVerifyUpdateBeforeExtraction=YES, optional SURequireSignedFeed. Do NOT set SUEnable*Service keys (sandbox-only).
- LSUIElement apps: use gentle reminders (SPUStandardUserDriverDelegate supportsGentleScheduledUpdateReminders etc.) → show "Update available" in status menu/notification. Driver: SPUStandardUpdaterController(startingUpdater:updaterDelegate:userDriverDelegate:), bind menu item to publisher(for: \.canCheckForUpdates). Immediate install hook: updater(_:willInstallUpdateOnQuit:immediateInstallationBlock:).
- Keys/appcast/CI: generate_keys (-x/-f export/import); CI secret → --ed-key-file; generate_appcast <dir> --download-url-prefix <gh release url>/ -o appcast.xml (deltas if previous zips present; v4 delta default); enclosures zip (`ditto -c -k --sequesterRsrc --keepParent`) or APFS+lzfse DMG; GH Actions jozefizso/setup-sparkle@v2. Patterns: CodexBar/openclaw commit appcast.xml to main served raw; Presentify → GitHub Pages; Ghostty own host. Homebrew cask: auto_updates true + livecheck :sparkle.
- Sparkle does NOT manage launchd agents; after update the agents still run OLD binaries (old inodes). Convention: on app launch, if bundle version changed → register() each agent (idempotent) then `launchctl kickstart -k gui/$UID/<label>`. Installer strips quarantine, validates signature/Team ID before swap.
- Alternatives: Squirrel.Mac (Electron only), mxcl/AppUpdater (DMG-on-GH-releases only, tiny), custom checkers (notify only). Sparkle = standard (Tailscale standalone, Ghostty, CodexBar...).

## Self-install / artifact / CLI on PATH
- LetsMove dormant (ObjC, no SPM, 2020). DMG makes it moot; add ~40-line guard "running from DMG/translocated → move me".
- Notary accepts zip/DMG/pkg; staple app/DMG/pkg (not zip). Convention: DMG for first install (create-dmg or hdiutil APFS ULFO + codesign + notarize + staple), zip for Sparkle. pkg only if root installs. Homebrew CASK is an expected secondary channel for dev tools (app, binary stanza, auto_updates, uninstall launchctl/quit, zap trash).
- CLI on PATH survey: old-era editors symlink /usr/local/bin via osascript admin (VS Code, Zed w/ unprivileged-first, GitHub Desktop, Nova, Tower); CLI-first modern tools use user bin dir + rc PATH line (OrbStack ~/.orbstack/bin + compat symlinks, Docker ≥4.18 ~/.docker/bin option, Cursor agent ~/.local/bin, Claude Code ~/.local/bin + ~/.zshrc, Warp). Ghostty: no symlink, sets PATH for own shells. Recommendation: ~/.local/bin symlink without prompt + guarded PATH line with consent; /usr/local/bin opt-in via Zed pattern.
- Claude Code precedent: ~/.local/bin/claude symlink → ~/.local/share/claude/versions/.

## SMAppService / launchd
- API macOS 13+: agent(plistName:) — plist in Contents/Library/LaunchAgents; BundleProgram (bundle-relative; Contents/MacOS safest); register() bootstraps immediately + each login (kSMErrorAlreadyRegistered if already; kSMErrorLaunchDeniedByUser); unregister() terminates running job; status notRegistered/enabled/requiresApproval/notFound; openSystemSettingsLoginItems().
- Multiple agents per app: yes, one plist each; all show as ONE switch under the app in Login Items & Extensions; bundled agents auto-associate (AssociatedBundleIdentifiers is for legacy plists; harmless). One "Background Items Added" notification/day; macOS 26 additionally prompts about background tasks continuing after quit (uncertain UX). MDM pre-approval possible. `sfltool resetbtm` resets DB.
- Restart: no API; unregister→register needs ~500ms sleep (EPERM otherwise) and kills job; `launchctl kickstart -k gui/$UID/<label>` restarts in place (DTS recommends kickstart for starting; widely used; not formally "the SMAppService way"). Don't mix SMAppService with launchctl bootstrap of same plist. After update: register() once then kickstart -k.
- Upgrade trap: keep Label, Team ID, and helper code-signing identifier stable (launch constraint violation otherwise — Mozilla VPN). Bundle-id change: BTM keyed by bundle id/Team ID/path/UUID; stale entries linger until sfltool resetbtm + reboot; unregister BEFORE renaming.
- KeepAlive: true unconditional (ThrottleInterval default 10s); {SuccessfulExit:false} restart on non-zero; Crashed; PathState; RunAtLoad.
- TCC: app that registered via SMAppService = responsible code → FDA on app flows to its agents (since 11.4 helpers don't inherit via ad-hoc parentage); children spawned by agent stay in chain; daemonizing/re-exec can break it.

## Signing / notarization / Bun
- Flow: sign all Mach-O inside-out Dev ID `--options runtime --timestamp`; ditto zip; notarytool submit --wait; stapler staple app/dmg; zip can't staple (staple app, re-zip). Hardened runtime on every executable incl. rt; no get-task-allow; XML entitlements.
- Bun entitlements: template has 5 keys; actually needed: allow-jit (JSC MAP_JIT); allow-unsigned-executable-memory maybe; disable-library-validation only for non-Team dylibs/native addons; dyld-env only for DYLD_*. Recommend start allow-jit only, test; Bun ≥1.2.4 signing; 1.3.12 unsignable (fixed 1.3.13).
- Quarantine: downloads by a non-sandboxed app are NOT quarantined unless LSFileQuarantineEnabled=YES (don't set). Browser zip → translocation until moved; DMG avoids. `ditto -x -k` to avoid ._* pollution.
