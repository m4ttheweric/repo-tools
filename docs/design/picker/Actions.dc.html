Action registry — declare once, every surface is derived

A caller defines actions; the component owns presentation and dispatch. The keybar, right-click menu, ctrl-k menu, ⌃-held key map, and clickable keys are all renderings of the same registry — a caller never wires a surface by hand. Defaults (select / cancel / back) exist without declaring anything. The result names the action: {action, value, query}.

One declaration

actions: [
  { id: "open",      label: "open",          key: "enter",  scope: "item", primary: true },
  { id: "cd-sel",    label: "cd selected",   key: "ctrl-space", scope: "item" },
  { id: "editor",    label: "open in editor", key: "ctrl-o", scope: "item", group: "act" },
  { id: "reveal",    label: "reveal in finder",                scope: "item", group: "act" },  // no key: menus only
  { id: "cd-here",   label: "cd here",       key: "ctrl-h", scope: "global" },
  { id: "sort",      label: "sort",          key: "ctrl-s", scope: "global", group: "view" },
]
derived, for free: keybar (grouped, right-pinned quit) · right-click menu on any row (item scope + global) · ctrl-k on the cursor row (same menu) · ⌃-held full key map · clickable keybar · dispatch back to the caller as {action: "editor", value: "d:gitq"}
