Enriched rows — the flatten step dies with fzf

lib/enrich.ts already produces a split row (leading + right-pinned trailing) for the runner; the fzf path flattens it into one string because fzf can't do anything else. The new row model consumes the split form natively: the status cluster is pinned to the right edge and never truncates, the title clips instead — the exact behavior the runner already has. Ticket state badges keep Linear's own stateColor (dynamic hex, not a theme token) — the row model must carry arbitrary hex per segment, not just theme tones.

Incremental enrichment

Today rt cd blocks on a spinner before the picker opens (unless the daemon cache hits). The component's row-update channel (the same one watch/reload use) makes the better story free: open instantly with dirName · branch, then the enrichment push lands and rows gain titles, badges, and glyph clusters in place — filter and cursor untouched. One mechanism, three consumers: watch, reload, enrich.
